              YOUR PREFERENCES

              Make it work for you

              Core checks work immediately. Optional services use your own local setup or key, and never change the configuration score.

              One-time local setup

              Install Ollama, open it and keep it running, then download the model once:

              ollama pull qwen3.5:2b-q4_K_M

              Qwen 3.5 2B is about a 1.9 GB download, plus Ollama. Running it needs additional memory and processing power; speed depends on your computer. Verifact does not install or download anything automatically.

              Kept in this local app’s memory for this session. Never saved in browser storage, written into the code, or shared with other users.

              Google Safe Browsing Not connected

              Optional known-threat lists. Free for non-commercial use; Google account, API activation and your own key required. Commercial projects need a suitable service such as Web Risk.
